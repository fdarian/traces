## Import

```ts
import { SkeletonRow } from '@traces/react'
```

## Props

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `height` | `number` | no | `32` | Row height in pixels |
| `className` | `string` | no | — | Additional CSS class on the root element |

## Usage

```tsx
import { SkeletonRow } from '@traces/react'

// render 5 skeleton rows while loading
{isLoading && Array.from({ length: 5 }, (_, i) => (
  <SkeletonRow key={i} />
))}

// match a taller row geometry
<SkeletonRow height={48} />
```

## Behavior

- uses the `shimmer` keyframe from `@traces/react/theme.css` — a CSS gradient sweep on `--bg-subtle`
- the animation respects `prefers-reduced-motion: reduce` (defined in `theme.css`)
- `height` controls the `px` height; width is always 100%
