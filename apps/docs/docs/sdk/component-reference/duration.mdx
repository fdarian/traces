---
title: Duration
description: Renders a millisecond duration with the number in primary text and the unit de-emphasized.
---

<Duration ms={142} />

<Duration ms={1450} />

<Duration ms={62300} />

## Import

```ts
import { Duration } from '@traces/react'
```

## Props

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `ms` | `number` | yes | — | Duration in milliseconds |

## Usage

```tsx
import { Duration } from '@traces/react'

<Duration ms={span.durationMs} />
```

## Formatting

| Input | Output |
|---|---|
| `< 1000ms` | `142ms` |
| `>= 1000ms` | `1.45s` |

The number renders in `--text-primary` with Geist Mono + `tabular-nums` (`.font-data`). The unit (`ms` or `s`) renders in `--text-tertiary`.
