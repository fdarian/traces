## Import

```ts
import { ServiceBadge, serviceColorValue } from '@traces/react'
```

## Props

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `name` | `string` | yes | — | Service name |

## Usage

```tsx
import { ServiceBadge } from '@traces/react'

<ServiceBadge name={trace.rootService} />
```

The color is derived from a deterministic hash of the service name — the same name always renders the same hue, across renders, sessions, and instances.

## `serviceColorValue`

Returns the raw `oklch(...)` CSS color string for a service name. Use this when you need the color outside a React component:

```ts
import { serviceColorValue } from '@traces/react'

const color = serviceColorValue('checkout-service')
// → "oklch(0.72 0.14 187)"

// apply directly to a canvas or SVG element
ctx.fillStyle = serviceColorValue(service.name)
```
