title: StacktraceBlock
description: Styled stacktrace renderer — parses Node/Java/Python frames and dims library frames to 0.6 opacity.
---

  type="TypeError"

  stacktrace={`TypeError: Cannot read properties of undefined (reading 'userId')
    at getUserCart (/app/src/services/cart.ts:42:18)
    at async processCheckout (/app/src/routes/checkout.ts:91:22)
    at async handler (/app/src/server/router.ts:14:5)

/>

## Import

```ts
import { StacktraceBlock } from '@traces/react'
```

## Props

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `type` | `string` | yes | — | Exception type, e.g. `"TypeError"` |
| `message` | `string` | yes | — | Exception message |
| `stacktrace` | `string` | yes | — | Raw stacktrace string (Node, Java, or Python format) |

## Usage

```tsx
import { StacktraceBlock } from '@traces/react'

// typically pulled from an exception span event attribute
const exceptionAttr = span.events
  .find((e) => e.name === 'exception')
  ?.attributes

<StacktraceBlock
  type={exceptionAttr?.find((a) => a.key === 'exception.type')?.value as string}
  message={exceptionAttr?.find((a) => a.key === 'exception.message')?.value as string}
  stacktrace={exceptionAttr?.find((a) => a.key === 'exception.stacktrace')?.value as string}
/>
```

## Behavior

- parses Node.js (`at fn (file:line:col)`), Java (`at pkg.Class.method(File.java:line)`), and Python (`File "path", line n, in fn`) stacktrace formats via `parseStackFrames`
- app frames (your code) render at full opacity; library frames (path contains `node_modules`, `vendor/`, `/site-packages/`, `venv/`, `.venv/`, `dist/`, or `webpack/`) render at 0.6 opacity
- uses `.font-data` (Geist Mono + tabular-nums) for frame text
- `type` and `message` render in the header above the frame list
