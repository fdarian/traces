## What is traces?

**traces** is a lightweight observability dashboard. Point it at an existing Jaeger v2 instance and get:

- a home overview with error rates and request volume
- a trace explorer with waterfall view
- an error aggregation view grouped by exception type
- per-service filtering across all views

The UI components ship as a publishable React SDK (`@traces/react`) so you can embed them in your own app.

## Two things in one

| | |
|---|---|
| **App** (`apps/web` + `services/engine`) | Self-hosted dashboard: a web UI plus a headless engine that reads Jaeger. Bring a Jaeger v2 URL, get a full observability UI. |
| **SDK** (`@traces/react`) | Publishable component library. Use the waterfall, trace list, issue list, and more in any React app. |
