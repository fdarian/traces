All configuration is read at startup via Effect `Config`. No restart-on-change; restart the process to apply changes.

## App and ingester variables

### Jaeger connection

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `JAEGER_URL` | string | `http://localhost:16686` | base URL for all Jaeger v3 API calls — no trailing slash |

`JAEGER_URL` must point at the Jaeger HTTP query endpoint. all API calls are proxied through the app server, so Jaeger does not need to be reachable from the browser.

```bash title=".env.local"
JAEGER_URL=http://jaeger.internal.example.com:16686
```

### Storage

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `DATABASE_URL` | string | _(absent)_ | Postgres connection string — presence switches the storage driver to Postgres |
| `TRACES_DB` | string | `./traces.db` | SQLite file path — only used when `DATABASE_URL` is absent |

<Callout type="info">
**storage selection**: if `DATABASE_URL` is absent, the issue store uses SQLite at the path given by `TRACES_DB`. if `DATABASE_URL` is set, it uses Postgres and `TRACES_DB` is ignored. migrations run automatically at startup for both drivers. see [self-hosting](/docs/app/self-hosting) for the SQLite vs. Postgres tradeoff.
</Callout>

### Ingester

The background ingester polls Jaeger on a fixed interval and copies error spans into the local issue store. All timing values are in milliseconds.

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `INGEST_POLL_INTERVAL_MS` | number | `30000` (30 s) | how often the ingester polls Jaeger for new traces |
| `INGEST_TRACE_LIMIT` | number | `200` | max traces fetched per service per poll window (maps to Jaeger `query.num_traces`); hitting this limit triggers adaptive window shrink |
| `INGEST_OVERLAP_MS` | number | `60000` (1 m) | how far before the cursor each poll reaches back, to catch late-arriving spans |
| `INGEST_INITIAL_LOOKBACK_MS` | number | `3600000` (1 h) | how far back the first poll reaches for a service that has no cursor yet |

`INGEST_TRACE_LIMIT` caps how many traces are fetched in a single Jaeger request. when the response hits the limit, the ingester halves the next window to avoid missing spans — see [concepts → ingester polling](/docs/app/concepts#ingester-polling--cursors) for details.

## Seed script variables

These are plain `process.env` values read by `scripts/seed.ts`. they control test-data generation only and have no effect on the running app.

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `TRACE_COUNT` | number | `50` | number of root traces to emit |
| `ERROR_RATE` | number | `0.15` | fraction of spans that record an error (0–1) |
| `OTLP_ENDPOINT` | string | `http://localhost:4318/v1/traces` | OTLP HTTP receiver URL for the seed exporter |

```bash
TRACE_COUNT=200 ERROR_RATE=0.4 bun run scripts/seed.ts
```
