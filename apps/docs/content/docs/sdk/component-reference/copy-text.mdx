---
title: CopyText
description: Monospace text with a copy-to-clipboard button — shows a "copied" confirmation on success.
---

<CopyText value="abc123def45678901234567890abcdef" />

With custom children:

<CopyText value="abc123def45678901234567890abcdef">trace-id: abc123…</CopyText>

## Import

```ts
import { CopyText } from '@traces/react'
```

## Props

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `value` | `string` | yes | — | The string to copy to the clipboard |
| `className` | `string` | no | — | Additional CSS class on the root element |
| `children` | `ReactNode` | no | `value` | Display content; if omitted, the raw `value` is rendered |

## Usage

```tsx
import { CopyText } from '@traces/react'

// show the raw value
<CopyText value={trace.traceId} />

// custom display text
<CopyText value={trace.traceId}>
  {trace.traceId.slice(0, 8)}…
</CopyText>
```

## Behavior

- clicking the copy icon writes `value` to the clipboard via the Clipboard API
- the icon switches to a checkmark for ~1.5s as confirmation, then reverts
- text renders with `.font-data` (Geist Mono + tabular-nums)
