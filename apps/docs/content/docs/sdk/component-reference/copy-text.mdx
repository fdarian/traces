---
title: CopyText
description: Monospace text with a copy-to-clipboard button.
---

## Import

```ts
import { CopyText } from '@traces/react'
```

## Props

Check the component source for the current prop signature — it accepts the text to display and copy.

## Usage

```tsx
<CopyText value="abc123def45678901234567890abcdef" />
```

Clicking the copy icon writes the value to the clipboard. The icon briefly changes to a checkmark as confirmation.
