---
title: EmptyState
description: Dot-grid empty placeholder with a message and optional action slot.
---

<EmptyState message="no traces in this range" />

## Import

```ts
import { EmptyState } from '@traces/react'
```

## Props

| Prop | Type | Required | Default | Description |
|---|---|---|---|---|
| `message` | `string` | yes | — | Primary message shown in the center |
| `action` | `ReactNode` | no | — | Optional action element (e.g. a button or link) rendered below the message |

## Usage

```tsx
import { EmptyState } from '@traces/react'

// basic
<EmptyState message="no traces in this range" />

// with action
<EmptyState
  message="no issues found"
  action={
    <button onClick={resetFilter}>clear filter</button>
  }
/>
```

## Behavior

- renders a faint 16px dot-grid background via `radial-gradient`
- message in `--text-secondary`
- `action` renders below the message; style it yourself (e.g. give it the `--accent` color)
