---
title: EmptyState
description: Dot-grid empty state with a message and optional action.
---

## Import

```ts
import { EmptyState } from '@traces/react'
```

## Props

Check the component source for the current prop signature — it accepts a message string and an optional action element.

## Usage

```tsx
<EmptyState message="no traces in this range" />
```

Renders a faint 16px dot-grid background (`radial-gradient`), the message in `--text-secondary`, and an optional accent-colored action.
