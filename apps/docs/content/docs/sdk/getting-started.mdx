## Install

```bash
npm install @traces/react lucide-react
# or
bun add @traces/react lucide-react
```

`lucide-react` is a peer dependency required by several components.

## Fonts

The SDK uses Geist Sans and Geist Mono. Install them:

```bash
npm install @fontsource-variable/geist @fontsource-variable/geist-mono
```

Import in your app's global CSS or entry point:

```css
@import '@fontsource-variable/geist/index.css';
@import '@fontsource-variable/geist-mono/index.css';
```

## Theme

Import the compiled theme CSS — this provides all CSS variable tokens and Tailwind utility classes used by the components:

```css
@import '@traces/react/theme.css';
```

Or in JavaScript:

```ts
import '@traces/react/theme.css'
```

## Your first component

```tsx
import { TraceWaterfall } from '@traces/react'
import type { Trace } from '@traces/react'

const trace: Trace = { /* ... */ }

export function MyWaterfall() {
  return <TraceWaterfall trace={trace} animateBars />
}
```

## Navigation

All components that link to other pages use callback props (`getTraceHref`, `getIssueHref`, etc.) instead of hard-coded routes. Wire them to your router:

```tsx
// React Router
getTraceHref={(traceId) => `/traces/${traceId}`}

// Next.js
getTraceHref={(traceId) => `/traces/${traceId}`}
```
